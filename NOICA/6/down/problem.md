## T1.活动（activity）

## 问题描述

超市里，有 $n$ 种物品，第 $i$ 种物品的重量为 $i$，且每种物品都有无限多个。

有一天，超市举办了一个活动。活动的规则是：首先给出一个目标重量 $x$。

首先你一开始有一个空篮子，初始时篮子内物品总重量为 $0$。你每次可以将一个物品放入篮子，但假设当前篮子内物品总重量为 $w$，则只能选择重量 $≥ w$ 的物品放进篮子。

你可以按照规则放多次，但不能把已经在篮子里的物品取出篮子。如果你可以按照规则，使得篮子内物品的总重量刚好为 $x$，则超市就赠送你一个小礼品。

牛牛发现了这个活动的一个必胜策略，他参加了很多次活动，导致超市面临亏损。

于是在牛牛打算再次参与活动时，超市老板对牛牛提出挑战，如果牛牛可以不使用第 $y$ 种物品的前提下，仍然使篮子内物品的总重量刚好为 $x$，则超市老板就赠送牛牛一份大礼品，否则牛牛将再也不许参加活动。

牛牛欣然接受，他只是觉得无聊。于是他打算考考你，在不使用第 $y$ 种物品的前提下，他可以有多少种合法的放物品方案，使得篮子内物品的总重量刚好为 $x$。

两种方案不同当且仅当牛牛在两种方案中篮子内物品的数量不同，或者两种方案中第 $k$ 次放到篮子的物品种类不同。
由于方案数可能很大，他只需要你输出方案数除以 $998244353$ 的余数就可以啦。

## 输入格式

第一行，三个正整数 $n， x， y$ ，以空格相隔。

## 输出格式

一行，一个整数，表示方案数除以 $998244353$ 的余数。

#### 样例 $1$ 输入

```input1
5 7 3
```
#### 样例 $1$ 输出

```output1
3
```
## 样例1说明

$3$ 种方案分别是：
$(1) $放入 $1$,放入 $1$,放入 $5$
$(2) $放入 $1$, 放入 $2$, 放入 $4$

$(3)$ 放入 $2$, 放入 $5$。

#### 样例 $2$ 输入

```input2
8 15 4
```
#### 样例 $2$ 输出

```output2
4
```

#### 样例 $3$ 输入

```input3
12345 4321 24
```

#### 样例 $3$ 输出

```output3
795333476
```

## 数据范围

对于 $10\%$ 数据，满足$1 ≤ n， x ≤ 10$。

对于 $40\%$ 数据，满足$1 ≤ n，x ≤ 1000$。

对于 $100\%$ 数据，满足$1 ≤ n，x ≤ 100000，1 ≤ y ≤ n$。

## T2.期末测试（road）

## 题目描述

小美准备前往学校参加奥信队的期末测试。突然，电话响了，JY 告诉她有 $k$ 位同学睡过头了。于是善良的小美决定从家里出发，按任意顺序前往这 $k$ 位同学的家叫醒他们，最后抵达学校参加考试。

给定一张有 $n$ 个节点、$m$ 条有向边的地图，请你帮助小美求出上述路线的最短总距离。

## 输入格式

第一行包含五个整数 $n, m, k, s, t$，分别表示节点数、有向边数、需要叫醒的同学数、起点编号和终点编号。

接下来 $m$ 行，每行三个整数 $x, y, z$，表示一条从 $x$ 到 $y$、长度为 $z$ 的有向边。

接下来 $k$ 行，每行一个整数，表示一位同学家的节点编号。

## 输出格式

输出一个整数，表示最短距离。若不存在可行方案，输出 $-1$。

#### 样例 $1$ 输入

```input1
3 3 2 1 1
1 2 1
2 3 1
3 1 1
2
3
```

#### 样例 $1$ 输出


```output1
3
```

## 样例解释

路径为 $1 \to 2 \to 3 \to 1$。

## 数据范围

- 对于 $20\%$ 的数据，$n \le 10$；
- 对于 $50\%$ 的数据，$n \le 1000$；
- 另有 $20\%$ 的数据，$k = 0$；
- 对于 $100\%$ 的数据，$n \le 50000$，$m \le 100000$，$0 \le k \le 10$，$1 \le z \le 5000$。

## T3.宇宙 (universe)

### 题目背景

我写证明只用三个词——【显然可得】、【显然可见】、【显然可知】——这不是很显然吗？

科学没有界限，我更没有。

### 题目描述

在 ybt 中，大黑塔是智慧的代表。其所属的【天才俱乐部】更是信奉代表智慧的【智识】星神。

> 连宇宙的终极奥秘都不知道，还有心思聊生活？
> ——大黑塔

为了检测你有没有能力聊生活，大黑塔出了一道题。

众所周知，有质量的物体会对其周边产生引力效果，下图生动地解释了这一点。

![R-C](https://cdn.luogu.com.cn/upload/image_hosting/n3je7ovo.png)

螺丝咕姆发现宇宙是没有边界的，不方便出 oi 题，所以简化为 $n \times n$ 的网格图。

阮·梅发现引力场是环状结构，不方便出 oi 题，所以简化为方形结构。

鉴于你上次在真理医生的考试中不及格，所以真理医生把无数个天体修改为 $k$ 个天体。

如果两个天体之间的距离太过遥远，那么其间的万有引力是极小的，可以忽略不计（视作为 $0$）。

> 温馨提示：在星核扰动下，你认知中的万有引力定律在大黑塔出的题目中并不适用。

在宇宙各处，第 $i$ 个天体坐标为 $(x_i,y_i)$，质量为 $M_i$。对于宇宙中的一个位置，定义第 $i$ 个天体对该位置的“引力效果”为 $\max (0,M_i - d)$，其中 $d$ 表示该位置到第 $i$ 个天体坐标的**切比雪夫距离**。

> 切比雪夫距离：二点之间横坐标之差的绝对值与纵坐标之差的绝对值的最大值。形式化地，对于二维平面上的两个点 $(x_1,y_1) ,\ (x_2,y_2)$，其切比雪夫距离为 $\max(|x_1-x_2|,|y_1-y_2|)$。

对于一个位置，定义该位置受到的**总引力效果**为该位置受到的所有引力效果的**数量和**。如果其不受到任意一个天体的引力效果作用，那么该位置的总引力效果为 $0$。

大黑塔想要知道，宇宙中有多少个位置的总引力效果是 $\le p$ 的。

> 温馨提示：在星核扰动下，不保证天体的坐标两两不同。

### 输入格式

从文件 $\texttt{universe.in}$ 读入数据。

输入的第一行包含三个整数 $n,k,p$，分别表示网格图的尺寸、宇宙中的天体个数以及宇宙中合法位置所需满足的范围条件。

接下来 $k$ 行，第 $i$ 行包含三个整数 $x_i ,\ y_i ,\ M_i$，分别表示第 $i$ 个天体的横坐标、纵坐标、质量。

### 输出格式

输出到文件 $\texttt{universe.out}$ 中。

输出一行一个整数，表示答案。

### 样例 $1$ 输入

```text
4 2 1
2 2 2
3 3 2
```

### 样例 $1$ 输出

```text
12
```

### 样例 $1$ 解释

总引力效果分布图如下：

```text
1 1 1 0
1 3 2 1
1 2 3 1
0 1 1 1
```

除了中心的四个位置，其它位置都是符合条件的，共计 $12$ 个点。

### 样例 $2$

见下发文件的 $\texttt{universe2.in}$  与 $\texttt{universe2.ans}$。

该组样例满足 $n \le 100$。

### 样例 $3$

见下发文件的 $\texttt{universe3.in}$  与 $\texttt{universe3.ans}$。

该组样例满足 $p=0$。

### 样例 $4$

见下发文件的 $\texttt{universe4.in}$  与 $\texttt{universe4.ans}$。

该组样例满足 $M_i \le 20$。

### 样例 $5$

见下发文件的 $\texttt{universe5.in}$  与 $\texttt{universe5.ans}$。

## T4.翻牌很爽（cards）

## 【题目描述】

给定两个仅包含非负整数且长为 $n$ 的序列 $A$ 和 $B$。

定义这两个序列的权值为 $\operatorname{Mex}(\{A_1,\dots,A_n\}) + \operatorname{Mex}(\{B_1,\dots,B_n\})$。其中 $\operatorname{Mex}(S)$ 表示最小的未在可重集 $S$ 中出现的非负整数。

你可以进行若干操作，形如：选择 $1\le i\le n$，交换 $A_i$ 和 $B_i$。

求出进行若干次操作后两个序列的权值最大值。
