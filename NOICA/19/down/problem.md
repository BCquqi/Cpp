# T1  平方数对（sqrt）

给定两个正整数 $n, m$ 。
求有多少有序正整数数对 $A, B$ 满足 $1 \leq A \leq n, 1 \leq B \leq m$ 且 $(\sqrt{A}+\sqrt{B})^{2}$ 是正整数。

### 【输入格式】

从文件 `sqrt.in` 中读入数据。
一行两个正整数 $n, m$ 。

### 【输出格式】

输出到文件 `sqrt.out` 中。
一行一个正整数，表示满足条件的数对个数。

### 【样例1输入】

```
5 5
```


### 【样例1输出】

```
7
```


### 【样例1解释】

合法的 $(A, B)$ 分别为:$(1,1),(1,4),(2,2),(3,3),(4,1),(4,4),(5,5) 。$

### 【样例2输入】

```
469 916
```

### 【样例2输出】

```
2549
```

### 【子任务】

对于 $20 \%$ 的数据 $n, m \leq 1000$ 。  
对于 $50 \%$ 的数据 $n, m \leq 10^{5}$ 。  
对于 $100 \%$ 的数据 $n, m \leq 2 \times 10^{6}$ 。

# T2 魔法阵（magic）  

### 【题目描述】

有一个 $n\times m$ 的魔法阵，$(i,j)$ 表示从上到下第 $i$ 行，从左到右第 $j$ 列的格子，格子 $(i,j)$ 上有权值 $w_{i,j}$，现在，小 $L$ 要携带一个变量 $v$ 走遍这个魔法阵（每个格子恰好经过一次）。

具体走法如下：

1. 小 $L$ 可以选择任意一个格子作为起点，设其为 $(x_s,y_s)$，令 $v\gets w_{x_s,y_s}$。
2. 之后每一步小 $L$ 可以选择向上下左右任意方向移动一格，分别用 `U` `D` `L` `R` 表示，设新的位置为 $(x',y')$，$v\gets v+w_{x',y'}$
3. 重复步骤 2 直到每个格子恰好经过一次，你需要保证变量 $v$ 的值在任何时刻非负。

请构造一种可行的走法，或报告无解。

### 【输入格式】

从文件 $magic.in$ 读入。

第一行一个整数 $T$，表示测试数据组数。

对于每组数据：

- 第一行两个正整数 $n,m$，**保证 $n,m$ 均为偶数**。

- 接下来 $n$ 行，每行 $m$ 个整数，第 $i$ 行的第 $j$ 个整数为 $w_{i,j}$。


### 【输出格式】

向文件 $magic.out$ 输出。

对于每组数据：

- 如果有解，在第一行输出 `Yes`，在第二行输出起点位置 $(x_s,y_s)$，第三行输出 $nm-1$ 个字母（必须为 `U` `D` `L` `R` 之一），表示每一步移动的方向。如果有多解，输出任意一个即可。
- 如果无解，输出 `No` 即可。

### 【样例1 输入】

```
2
2 4
1 5 -6 -7
8 2 2 -1
2 4
5 3 -9 -1
2 -6 -8 3
```

### 【样例1 输出】

```
Yes
1 1
DRURDRU
No
```

### 【样例1 解释】

对于第一组数据，$v$ 的变化为 $1\to 9\to 11\to 16\to 10\to 12\to 11\to 4$，也存在其他可行解。

对于第二组数据，遍历完成后 $v$ 一定等于 $-11$，因此无解。

### 【样例2~6】

见下发文件，分别满足测试点2、4、5、6、15的限制条件。

### 【数据范围】

设 $S=\sum n\times m$，对每组测试数据均有：

- $n,m\le 10^3$，**保证 $n,m$ 均为偶数**
- $S\le 2\times 10^6$
- $\forall 1\le i\le n,1\le j\le m,|w_{i,j}|\le 10^9$

| 测试点编号  | $n\times m\le $ |    $S\le $     |  特殊性质  |
| :---------: | :-------------: | :------------: | :--------: |
|  $1\sim 2$  |      $10$       |     $100$      |     无     |
|     $3$     |      $20$       |     $200$      |     无     |
|     $4$     |      $50$       |     $500$      | $\text{A}$ |
|     $5$     |      $50$       |     $500$      |     无     |
| $6\sim 10$  | $2\times 10^3$  |     $10^6$     | $\text{A}$ |
| $11\sim 14$ |     $10^6$      |     $10^6$     |     无     |
| $15\sim 20$ |     $10^6$      | $2\times 10^6$ |     无     |

特殊性质 $\text{A}$：保证 $n=2$。

# T3 字符串（string）       



### 【题目描述】

小 $Y$ 喜欢一些字符串，小 $Y$ 不喜欢一些数字。

小 $Y$ 不喜欢的数字构成一个自然数区间 $S=\{x\in \N\mid L\le x\le R\}$，他喜欢的字符串 $s$ 满足对于所有 $k\in S$，$s$ 不存在一个长为 $2k$ 的子串，使得其中恰好包含 $0$ 和 $1$ 各 $k$ 个。

请你判断是否有一个恰好包含 $n$ 个 $0$ 和 $m$ 个 $1$ 的字符串是被小 $Y$ 所喜欢的。

### 【输入格式】

从文件 $string.in$ 读入。

第一行一个整数 $T$，表示测试数据组数。

对于每组数据：

输入一行四个整数分别表示 $L,R,n,m$。

### 【输出格式】

向文件 $string.out$ 输出。

对于每组测试数据，输出一行 `Yes` 或 `No`，分别表示是否存在满足要求的字符串。

### 【样例1 输入】

```
2
3 3 6 4
1 7 5 3
```

### 【样例1 输出】

```
Yes
No
```

### 【样例1 解释】

对于第一组数据，字符串 `1100000011` 是符合要求的。

对于第二组数据，包含 $5$ 个 $0$ 和 $3$ 个 $1$ 的字符串一定存在相邻的 `01` 或 `10`，因此对于 $k=1$ 一定不合法。

### 【样例 2~5】

见下发文件，分别满足测试点 2、8、12、13 的限制条件。

### 【数据范围】	

对所有数据均有：$1\le T\le 2\times 10^5$，$1 \le L\le R\le 10^{18}$，$0\le n,m\le 10^{18},n+m\ge 1$

| 测试点编号  |               特殊性质               |
| :---------: | :----------------------------------: |
|     $1$     |           $L\ge \max(n,m)$           |
|  $2\sim 3$  |        $T\le 1000,n+m\le 14$         |
|  $4\sim 7$  | $\sum \max(n,m,L,R)\le 5\times 10^3$ |
| $8\sim 11$  |                $L=R$                 |
|    $12$     |               $L+1=R$                |
| $13\sim 20$ |                  无                  |

# T4   左秉烛 (zuo)      

### 【题目背景】

*少年英才　初见锋芒　贵而知事　制币为念*

### 【题目描述】

**这是一道交互题。**

现在有一个长度为 $n$ 的 01 串 $S$，你的任务是确定 $S$ 的每一位。

你可以进行如下询问：

- 给出整数 $m$ 和两个长度为 $m$ 的转移数组 $a,b$ 。要求 $1\le m\le 1002,0\le a_i,b_i<m$ 。

交互库首先设置变量 $x=0$ ，接下来 $n$ 次操作，第 $i$ 次操作为，若 $S_i=0$ 则将 $x$ 变为 $a_x$ ，若 $S_i=1$ 则将 $x$ 变为 $b_x$ 。

在 $n$ 次操作结束后返回 $x$ 。

在 $1000$ 次询问内确定 $S$ ，并尽可能缩小每次询问中 $m$ 的最大值。

### 【实现细节】

下发了 `zuo_sample.cpp` 作为模板。建议在此基础上完成你的代码。

你需要实现如下函数

- `std::string solve(int id,int n)` 

其中 $n$ 为 $S$ 的长度，$id$ 为测试点编号。样例的 $id$ 为 $0$ 。

你可以调用如下函数。

- `int Query(int m, std::vector<int> a, std::vector<int> b)` 

其中 $m,a,b$ 的意义如上。

### 【编译和调试】

下发了 `grader.cpp` 。将 `grader.cpp` ，`zuo.cpp` ，`zuo.h` 放在同一文件夹下，执行如下命令：

```
g++ -std=c++14 -O2 -o grader grader.cpp zuo.cpp
```

生成的 `grader` 将从标准输入中读取 $n$ 和 $S$ 。

### 【数据范围】

对于 $100\%$ 的数据有 $N = 1000,S_i\in\{0,1\}$ 。

记 $M$ 为所有询问中 $m$ 的最大值，对于每个测试点，你能得到分数当且仅当 $M\le M_{lim}$ 。

注意 `grader` 只会返回 $M$ ，不会进行 $M\le M_{lim}$ 的比较。

交互库不是自适应的，这意味着在开始时答案就已经确定了。
