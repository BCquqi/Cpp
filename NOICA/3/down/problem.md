## T1.勇者斗恶龙（dragon）

## 问题描述

现在有一条 $n$ 头龙，生命值为 $h$，勇士想要打败这条作恶多端的龙。

勇士攻击第 $i$ 个头会造成 $min(h,atk_i)$ 点伤害，即龙的生命值减少 $min(h,atk_i)$ 点；但龙的第 $i$ 个头受到伤害后会恢复 $d_i$ 点生命值，即生命值增加 $d_i$ 。

勇士无法重复攻击同一个头，即他对于每个头最多只能攻击一次。当龙的生命值为 $0$ 时则视为被勇士打败，此时它不能再恢复生命值了。

勇士想要知道他是否能打败这头龙，如果能打败最少需要攻击多少次。

## 输入格式

第一行包含两个整数 $n,h$，分别表示龙的头的数量和龙的生命值。

接下来 $n$ 行，每行两个整数 $atk_i，d_i$，含义见【题目描述】。

## 输出格式

第一行输出 `Yes` 或 `No`，表示勇士是否能击败恶龙若能击败。

如果能打败，在第二行输出一个整数，表示打败这头龙所需的最小攻击次数。

### 样例1输入

```input1
3 5
2 3
2 0
1 0
```

### 样例1输出

```output1
Yes
3
```

### 样例2输入

```input2
3 6
2 3
2 0
1 0
```

### 样例2输出

```output2
No
```

### 样例3输入

```input3
请下载附加文件
```
### 样例3输出

```output3
请下载附加文件
```

## 样例1解释

只要最后一次攻击第一个头，就能刚好击败恶龙。

## 数据范围

对于所有测试数据：

$1\le n\le3\times{10}^5,0\le h\le{10}^9,1\le atk_i,d_i\le{10}^9$

每个测试点的具体限制见下表：

| 测试点编号        | $n≤$     | 特殊性质               |
| ----------------- | -------- | ---------------------- |
| 1,2,3,4           | $100$    | 无                     |
| 5,6,7,8,9,10      | $2000$   | 无                     |
| 11,12             | $3×10^5$ | 保证 $atk_i≤d_i$       |
| 13,14             | $3×10^5$ | 保证存在某一 $atk_i≥h$ |
| 15,16,17,18,19,20 | $3×10^5$ | 无                     |

## T2.守卫者的挑战（protect）

## 问题描述

打开了黑魔法师Vani的大门，队员们在迷宫般的路上漫无目的地搜寻着关押applepi的监狱的所在地。突然，眼前一道亮光闪过。

“我，Nizem，是黑魔法圣殿的守卫者。如果你能通过我的挑战，那么你可以带走黑魔法圣殿的地图……”

瞬间，队员们被传送到了一个擂台上，最初身边有一个容量为$K$的包包。

擂台赛一共有 $N$ 项挑战，各项挑战依次进行。第 $i$ 项挑战有一个属性 $a_i$，如果 $a_i\geq 0$，表示这次挑战成功后可以再获得一个容量为 $a_i$ 的包包；如果 $a_i=-1$，则表示这次挑战成功后可以得到一个大小为 $1$ 的地图残片。地图残片必须装在包包里才能带出擂台，包包没有必要全部装满，但是队员们必须把 【获得的所有的】地图残片都带走（没有得到的不用考虑，只需要完成所有 $N$ 项挑战后背包容量足够容纳地图残片即可），才能拼出完整的地图。并且他们至少要挑战成功$L$次才能离开擂台。

队员们一筹莫展之时，善良的守卫者Nizem帮忙预估出了每项挑战成功的概率，其中第 $i$ 项挑战成功的概率为 $p_i\%$。现在，请你帮忙预测一下，队员们能够带上他们获得的地图残片离开擂台的概率。

## 输入格式

第一行三个整数 $N,L,K$。

第二行 $N$ 个实数，第 $i$ 个实数 $p_i$ 表示第 $i$ 项挑战成功的百分比。

第三行 $N$ 个整数，第 $i$ 个整数 $a_i$ 表示第 $i$ 项挑战的属性值.

## 输出格式

一个整数，表示所求概率，四舍五入保留 $6$ 位小数。

### 样例1输入

```input1
3 1 0
10 20 30
-1 -1 2
```
### 样例1输出

```output1
0.300000
```

### 样例2输入

```input2
5 1 2
36 44 13 83 63
-1 2 -1 2 1
```
### 样例2输出

```output2
0.980387
```

### 样例3输入

```input3
请下载附加样例
```

### 样例3输出

```output3
请下载附加样例
```
## 样例解释

若第三项挑战成功，如果前两场中某场胜利，队员们就有空间来容纳得到的地图残片，如果挑战失败，根本就没有获得地图残片，不用考虑是否能装下；若第三项挑战失败，如果前两场有胜利，没有包来装地图残片，如果前两场都失败，不满足至少挑战成功次（）的要求。因此所求概率就是第三场挑战获胜的概率。

## 数据范围

对于 $30\%$ 的数据，保证 $0 \leq K \leq 10$，$0 \leq N \leq 10$，$-1 \leq a_i \leq 100$，$0 \leq L \leq N$，$0 \leq p_i \leq 100$。

对于 $100\%$ 的数据，保证 $0 \leq K \leq 2000$，$0 \leq N \leq 200$，$-1 \leq a_i \leq 1000$，$0 \leq L \leq N$，$0 \leq p_i \leq 100$。

## T3.积因你太美（prodiv）

# 积因你太美（prodiv）

### 【题目描述】

记 $\tau(x)$ 为 $x$ 的正因数个数。

给定长为 $n$ 的正整数序列 $a_1,\dots,a_n$ 和正整数 $k$，你需要确定一个正整数序列 $b$ 满足 $\displaystyle k \bmod \left(\prod_{i=1}^n b_i\right) = 0$。

最大化 $\displaystyle \prod_{i=1}^n \tau(a_i\times b_i)$。

### 【输入格式】

从文件 **prodiv.in** 中读入数据。

第一行两个整数 $n$ 和 $k$。

接下来一行 $n$ 个正整数，第 $i$ 个表示 $a_i$。

### 【输出格式】

输出到文件 **prodiv.out**。

一行一个整数，表示最大的 $\displaystyle \prod_{i=1}^n \tau(a_i\times b_i)$ 对 $998244353$ 取模后的值。

### 【样例 1 输入】

```
3 60
8 243 250

```

### 【样例 1 输出】

```
2304

```

### 【样例 1 解释】

一种最优的序列 $b$ 为 $[15,4,1]$。

### 【样例 2】

见选手目录下 **prodiv/ex_prodiv2.in** 和 **prodiv/ex_prodiv2.out**。

### 【样例 3】

见选手目录下 **prodiv/ex_prodiv3.in** 和 **prodiv/ex_prodiv3.out**。

### 【数据范围与约定】

测试数据满足 $1\le n\le 3\times 10^5, 1\le a_i,k\le 3\times 10^5$。

| 子任务编号 |        特殊性质        | 分值 |
| :--------: | :--------------------: | :--: |
|    $1$     |         $k=1$          | $5$  |
|    $2$     |     $1\le n\le 5$      | $20$ |
|    $3$     |         $k=2$          | $15$ |
|    $4$     | $1\le n,a_i,k\le 10^4$ | $30$ |
|    $5$     |           -            | $30$ |

## T4.绅士（gentleman）

## 绅士（gentleman）

## 【题目背景】

摄政时代的英格兰乡间，舞会与拜访拉开了漫长社交季的帷幕。在那个为财产与门第而权衡婚事的年代，一位绅士在众人眼中的「身价」从不是一成不变的—人们的傲慢与偏见，会让这份评分日复一日地起落。

## 【题目描述】

某位绅士的身价用一个整数 $A$ 表示。约定社交季第1天他的身价为给定的初始值 $A$ ；从第2 天起，每天乡间的议论都会使其身价发生一次变化：当天的身价加上它在十进制表示下最大的那一位数字 $\operatorname{big}(A)$ ，再对 $M$（这片乡间所能容纳的身价上限，超出即回绕）取模。形式化地，

$$
A \leftarrow(A+\operatorname{big}(A)) \bmod M,
$$

例如 $\operatorname{big}(172)=7, \operatorname{big}(2014)=4$ 。
给定初始身价 $A$ 、模数 $M$ 与天数 $N$ ，请你求出第 $N$ 天时这位绅士的身价。

## 【输入格式】

从文件 gentleman．in 中读入数据。
输入只有一行，包含三个整数 $A, M, N$ ，含义如题目描述所述。

## 【输出格式】

输出到文件 gentleman．out 中。
输出一行一个整数，表示第 $N$ 天时该数的值。

## 【样例 1 输入】

1201420151

## 【样例 1 输出】

12014

## 【样例 1 解释】

$N=1$ ，即询问第1天的值，其值就是初始值 $A=2014$ 。

## 【样例 2 输入】

11425115

## 【样例2输出】

116

## 【样例 2 解释】

该数从第1天起依次为14，18，1，2，4，8，16，22，24，3，6，12，14，．．．，自第1天起以12为周期循环。第 115 天对应循环中的第 $((115-1) \bmod 12)+1=7$ 项，即16。

## 【样例 3】

见选手目录下的 gentleman／gentleman3．in 与 gentleman／gentleman3．ans。该样例满足 $M \leq 10^{6}$ ，对应测试点 $7 \sim 10$ 的约束条件。

## 【样例 4】

见选手目录下的 gentleman／gentleman4．in 与 gentleman／gentleman4．ans。该样例满足 $M, N \leq 10^{18}$ ，对应测试点 $14 \sim 20$ 的约束条件。

## 【数据范围】

对于所有测试数据，均有：

－ $1 \leq A<M$ ；
－ $1 \leq M \leq 10^{18}$ ；
－ $1 \leq N \leq 10^{18}$ 。

| 测试点编号   | $M \leq$  | $N \leq$  |
| ------------ | --------- | --------- |
| 1 ～ 3       | $10^{18}$ | $10^{6}$  |
| 4 ～ 6       | $10^{18}$ | $10^{8}$  |
| 7 ～ 10      | $10^{6}$  | $10^{18}$ |
| $11 \sim 13$ | $10^{8}$  | $10^{18}$ |
| 14 ～ 20     | $10^{18}$ | $10^{18}$ |
