# CSP-S 复习清单

## 1. 基础技巧

### 贪心
- 邻项交换法：排序后贪心
- 区间调度：按右端点排序
- 堆反悔贪心：允许撤回的选择
- 贪心与二分答案的组合
- 贪心策略证不出来时，写小数据暴力验证，不纠结证明

### 二分
- 整数二分：统一成一个模板，避免死循环
- 浮点二分：固定迭代 60 次
- 二分答案：单调性判定 + 上下界确定

### 前缀与差分
- 一维前缀和、二维前缀和
- 一维差分、二维差分

### 双指针
- 尺取法：单调性区间的 O(n) 扫描
- 左右指针收缩：去重、两数之和

### 其他
- 离散化：排序 + unique + lower_bound
- 倍增框架：LCA模板
- 归并排序、快速排序、堆排序
- 桶排序、计数排序、基数排序
- 分治框架、归并求逆序对

## 2. 数据结构

- 并查集：路径压缩 + 按秩/按大小合并
- 手写堆、priority_queue（含自定义比较）
- STL 容器：set、multiset、map、unordered_map、bitset、deque、pair
- STL 算法：sort、lower_bound、unique、next_permutation
- ST 表：RMQ
- 树状数组：单点改区间查、区间改单点查、区间改区间查、lowbit 原理
- 线段树：区间加/赋值 + 区间求和/最值，懒标记下传；
- 单调队列
- 单调栈：下一个更大元素、直方图最大矩形
- Trie：插入、查询
- 字符串哈希：双模或自然溢出
- 邻接表、链式前向星存图

## 3. 图论

- Dijkstra 堆优化
- Bellman-Ford；SPFA 仅用于判负环或小数据
- Floyd-Warshall
- Kruskal、Prim
- 拓扑排序，含判环
- Tarjan 求强连通分量、缩点
- Tarjan 求割点、割边
- 欧拉道路 / 欧拉回路：奇点 0 或 2 的判定 + Hierholzer 框架
- 二分图染色判定
- 二分图最大匹配：匈牙利算法
- LCA 倍增
- 树上差分、子树和
- 树的重心、直径
- DFS 序、欧拉序
- 换根 / 二次扫描
- 稀疏图与稠密图的存图方式、算法选择

## 4. 字符串

- KMP：next / fail 数组，求最小循环节
- Manacher
- 字符串比较与排序、字典序处理

## 5. 搜索

- DFS、BFS 框架，flood fill
- 记忆化搜索
- 双向 BFS
- 迭代加深搜索
- 剪枝：可行性剪枝、最优性剪枝、搜索顺序优化
- 位运算枚举子集、状压搜索

## 6. 动态规划

- 01 背包、完全背包、多重背包
- 多重背包的二进制拆分、单调队列优化
- 区间 DP
- 多维 DP
- 树形 DP：子树合并、树上背包
- 换根 DP
- 状压 DP：n ≤ 20 的集合划分、棋盘覆盖
- 滚动数组
- DP 初始化与转移顺序
- DP 优化：前缀和优化、单调队列优化、决策单调性

## 7. 数学

- 快速幂、龟速乘
- 线性筛、埃氏筛、欧拉函数线性筛
- gcd / lcm、扩展欧几里得
- 乘法逆元：费马小定理、扩展欧几里得、线性递推
- 组合数：阶乘 + 逆元预处理、杨辉三角
- Lucas 定理
- 矩阵乘法、矩阵快速幂
- 高斯消元
- 高精度：加、减、乘、除单精度
- 位运算技巧：lowbit、枚举子集 (s-1)&S、__builtin_popcount
- 同余、欧拉定理与欧拉函数、费马小定理
- 裴蜀定理、威尔逊定理、中国剩余定理
- 容斥原理、Catalan 数、鸽巢原理、二项式定理
- 多重集排列与组合、错排、圆排列
- 代数（高中部分）、几何（高中部分）
- 矩阵初等变换、特殊矩阵

## 8. 原理理解

- 时间复杂度、空间复杂度分析，按数据范围反推算法选择
- 哈希函数构造与冲突处理
- 树状数组 lowbit 原理
- 线段树懒标记含义
- 单调队列、单调栈的适用条件
- 强连通、双连通、割点割边的意义
- DAG 与拓扑序、二分图、欧拉图的判定条件
- DP 的状态设计、转移、优化思想
